# Архив прошлых версий сайта

Здесь лежат предыдущие версии `FLYXSE.github.io`, сохранённые при полной переработке сайта.
Каждая версия автономна и открывается локально как обычный `index.html`.

| Версия | Папка | Что это |
|---|---|---|
| v3 | [`v3/`](v3/) | Предыдущий публичный сайт: тёмный #101010, Python Backend / Telegram Bot Developer, секции «Стек», «Что я умею», «Проекты». Стили — `styles.css` + токены (`theme.css`, `variables.css`, `tokens.json`). |
| v2 | [`v2/`](v2/) | Более ранний вариант с вынесенными `assets/style.css` и `assets/script.js`. Файлы ассетов были удалены из репозитория отдельным коммитом — здесь они восстановлены из истории, поэтому версия снова рабочая. |
| v1 | [`v1/`](v1/) | Самый первый вариант: страница-терминал `about.sh` на JetBrains Mono, скан-линии, тёмно-синий фон. Весь CSS инлайн. |

Даты указаны по истории коммитов репозитория.

## Как посмотреть

Откройте `archive/vN/index.html` в браузере. Внешних зависимостей, кроме Google Fonts, нет.

## Важно

Эти папки не участвуют в работе сайта и не связаны с текущим `index.html` в корне.
Трогать их не нужно — это история.
